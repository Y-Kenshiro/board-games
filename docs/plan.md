# 企画メモ：BoardGames（仮）

## 一言で
ブラウザでオセロとチェスをCPU相手に遊べる、インストール不要のボードゲームアプリ。

## 誰の、どんな困りごとを解決するか
- 自分（＆友人）が、スマホでサッと1局遊びたいときに広告やアカウント登録なしで遊べる。
- 作る側としては「2つのゲームを1つのUIで動かす」設計と、ライブラリ組み合わせの練習になる。

## MVPの機能
1. トップ画面でオセロ／チェスを選んで開始できる
2. 盤面をタップして着手できる（置ける場所・動かせるマスをハイライト）
3. CPUが応手を返す（強さは弱〜中、固定1段階）
4. 勝敗・引き分け・パス（オセロ）・チェック（チェス）を判定して表示
5. 「はじめから」でリセットできる

## やらないこと
- オンライン対戦、ユーザー登録、戦績の保存
- CPUの強さ選択、自作の強いAI（強化学習など）
- 棋譜の保存・読み込み、待った
- 他ゲームの追加（将棋など）
→ これらはすべて「将来の拡張案」としてREADMEに書くだけ

## 技術スタック（候補・次ステップで確定）
- フロント：静的Webアプリ（HTML/CSS/JS または React）
- チェスのルール・CPU：既存ライブラリ（js-chess-engine など）
- オセロのルール・CPU：既存ライブラリ（npmのオセロ/リバーシ実装）
- 公開：Vercel または GitHub Pages（サーバー・DB・APIキー不要）

## 完成の定義
- 公開URLをスマホで開き、オセロとチェスをそれぞれCPU相手に最後まで1局プレイできる
- 不正な手が打てず、終局時に結果が表示される
- READMEに遊び方と技術構成が書いてある
